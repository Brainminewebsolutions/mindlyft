7. COURSE SYLLABUS — KEEP the modules, ADD descriptions
Keep all nine module titles exactly as they are. Add the one-line description shown under each.
H2: Course syllabus — 9 modules, 100 hours
H3: Module 1: Fundamentals of IT & OS Hardening
Operating system and infrastructure fundamentals, then locking them down.
The groundwork every other module depends on.

H3: Module 2: Networking & Network Security
How networks actually work and how they are attacked — protocols,
segmentation, firewalls and perimeter defence.

H3: Module 3: Cyber Security & Governance
Security frameworks, policy, risk and compliance. The structural layer that
turns individual controls into a security posture.

H3: Module 4: AI Security & Governance
The module that distinguishes this programme. Securing AI systems, governing
their use, and defending against AI-enabled attacks — material that pre-2023
security certifications do not cover.

H3: Module 5: OSINT & Dark Web Intelligence
Open-source intelligence gathering and dark web investigation — the
reconnaissance side of both attack and defence.

H3: Module 6: VAPT — Web & API Security Testing
Vulnerability assessment and penetration testing against web applications and
APIs. One of the most directly hireable skills on the syllabus.

H3: Module 7: Cloud Computing & Security
Securing cloud infrastructure — configuration, identity, and the
misconfigurations behind most cloud breaches.

H3: Module 8: Incident Response & Threat Intelligence
What to do when something has already happened: detection, containment,
response, and using threat intelligence to anticipate the next one.

H3: Module 9: Malware Analysis & Digital Forensics
Analysing malicious code and reconstructing what happened after a breach.
The investigative end of the discipline.
